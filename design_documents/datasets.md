# Dataset Description

Final validation of the tool will be performed on tissue-level data from the GTEx project. Specifically, transcripts per million (TPM) data from each tissue type will be individually downloaded and labelled, then the samples within each tissue will be aggregated into a median TPM value, and finally the RNA seq inputs will be compared against the array of tissue-specific median TPMs to identify the most probable tissue of origin. 

* Source website: https://gtexportal.org/home/downloads/adult-gtex/bulk_tissue_expression
* Specific data: .gct.gz files for each tissue listed under "Gene TPMs by tissue"
* Source version: Dataset will be sourced from GTEx Analysis V11. From website, "GTEx V11 updates the GTEx V10 data to use GENCODE 47 annotation. It contains no new samples or donors compared to V10."
* Data format: .GCT. This is a tab-delimited format for gene expression data. 
* Data structure: A GCT file is a matrix containing sample metadata and gene metadata, as well as their respective IDs. Genes are placed into the rows, and samples are placed into the columns. The TPM values reside in a data matrix at the interesection of the two heading groups. 
* Data size: Files for each tissue type range between 1 Mb and 100 Mb. Total expected size of all files is expected to be near 2.5 Gb. Given the median of samples will be determined for each tissue type, it is expected that a condensed file for all tissue types will be generated to be uploaded with the package. 
* GTEx reference database: A Snakemake pipeline `Snakefile` located in main directory is used to generate a condensed datasheet packaged with the tool. `\data\master_reference_matrix.csv` contains the GTEx reference file with dimensions 74269 x 68. Each row corresponds to a gene in Ensembl ID notation and each column corresponds to the median TPM value of the row gene's expression in the designated tissue. This 25Mb file is expected to be packaged with the tool.      
* Example dataset for using the tool: In order to test GTex-Tissue-Classifier during development, a smaller, simulated dataset will be employed. Specifically, using numpy, an example .GCT file will be generated containing 100 gene rows and 5 different samples. Importantly, the gene expression concentration will vary between tissues, such that example tissue A will have a subset of genes that are higher concentration than tissue B, to mimic the gene expression of actual tissues. Furthermore, simulated gene expression data from input samples will also be generated for testing input/cleaning features.

**Update 2/25**: The sample dataset will be improved based on the GTEx reference dataset. Given the original simulated datasets performed successfully, and the GTEx reference database has been succesfully built, the updated dataset will be generated to mimic the structure and distribution of the GTEx reference database file. 

* Data statistics: Dataset calculations will be performed as follows:
	1. Verification that TPMs per column sum to 1 million, to ensure proper TPM calculations from source.
	1. Calculation of median TPMs for each tissue.
	2. Variance calculations across tissues to isolate the 2000 most variable genes in each tissue, whcih will be used for identification. This removes uneeded genes that may weigh down the application. 

## Real dataset for answering a biological question using the tool.
* [Link to GSE126848 dataset](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE126848)
* **Descripton:** The chosen dataset is posted on NCBI GEO accession GSEGSE126848. It consists of a raw counts matrix of RNA Sequencing in multiple patients, including normal, healthy liver tissues. The dataset is structured as a .txt file with Ensembl Gene IDs in rows, and sample IDs in columns. As mentioned, the raw RNA seq counts are entered as the data values. The size of the matrix is 19786 genes x 57 sample columns, but the 14 healthy patient samples are of most interest to this study. The total size of the file is 1.3 Mb.
* **Justification:** This is a good example dataset because it provides an independent validation of the GTEx Tissue Classifier in a healthy tissue that has not been tested against the GTEx database. Given that this data was sequenced and uploaded from real experiments, it should provide a realistic example of the noise and distribution of genes that are typical of RNA sequencing runs. Also given the data is already labeled with Ensembl gene IDs, the preparatory steps for a classifier run only involve isolating a sample and calculating TPM values. (Note that CPM values could also be used in place of TPM. While the correlation may be less accurate because TPM is gene-length normalized, the calculations should generally identify the correct tissue. In this case the value column in the input should still be named 'TPM' to ensure it passes formatting checks.)  
* **Biological Question:** Is GTEx-Tissue-Classifier able to accurately identify the tissue type of independently sequenced healthy liver samples? Do sequenced samples in the same study show similar degrees of correlation? 
* **Expected Results:** It is expected the tool is able to accurately rank the tissue origin of the test sample as liver tissue. The user should receive an HTML report with a ranking of the top 5 most likely tissues of origin, in addition to their spearman correlation scores. Additionally, they should receive a heatmap image showing the top genes uniquely defining liver tissue, and how highly expressed those genes are in the sample input. Given the high amount of technical noise and the high number of 2000 variable features sampled to determine tissue types, it is expected that the correlation values will be relatively modest. However, GTEx Tissue Classifier will be tested on RNA seq samples from many tissue types and studies to ensure the overall accuracy of tissue classification decisions.
